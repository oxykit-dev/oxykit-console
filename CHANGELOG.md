## [0.1.0] - 2026-11-05

### Added

- Console for Mail, Render, and Flow. Sign-in is `/login`. Mail issues the session
- `config.json` next to `index.html` turns `mail`, `render`, and `flow` on or off after deploy. The app reads it on each load
- GitHub Release: one same-origin zip, `oxykit-console-{version}.zip` (not a per-OS host zip)
